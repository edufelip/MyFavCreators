# 0003 — Drizzle ORM over the Bun SQL driver

**Status:** accepted

## Context

The API runs on Bun and needs typed schema definitions, explicit migrations and the ability to
drop into raw SQL for set-based ranking work.

## Decision

Drizzle ORM `0.45.2` with Drizzle Kit `0.31.10`, using the officially supported Bun integration
`drizzle-orm/bun-sql` (and `drizzle-orm/bun-sql/migrator`). Both versions are pinned exactly.

- Only `packages/db` and `apps/api` may import database infrastructure.
- Migrations are committed artifacts generated by `drizzle-kit generate`. Automatic schema push
  is never used against any environment that matters, and migrations are excluded from `build`
  so a deploy cannot silently alter a production schema.
- Ranking uses Drizzle's `sql` template rather than the query builder, because the work is a
  window function over a CTE and reads better as SQL.

## Consequences

Rows returned by the driver are untyped, so `packages/db/src/row.ts` validates every column
before it reaches typed code rather than letting an implicit `any` propagate.

Replacing Drizzle would require a new ADR. The schema itself stays portable PostgreSQL and
depends on no hosting-provider extension.
